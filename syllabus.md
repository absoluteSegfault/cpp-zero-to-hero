# C++ Mastery Curriculum

## Level 1: Procedural & Functional Programming
- Core modern syntax (C++11 to C++23): `auto`, lambdas, range-based for loops.
- C++20 Concepts and constrained templates.

## Level 2: Memory & Structures
- Virtual memory mapping: Heap vs. Stack mechanics.
- RAII, smart pointers (`std::unique_ptr`, `std::shared_ptr`), and `placement new`.
- Memory profiling and leak detection with Valgrind.

## Level 3: Algorithms & Data Structures
- Standard library containers and custom memory allocators.
- Sorting algorithms and complexity analysis.
- Cache locality and memory-aligned data structures.

## Level 4: OOP & Internals
- Virtual functions, inheritance, and dynamic polymorphism.
- Under the hood: Virtual tables (vtables) and dynamic dispatch costs.
- Core design patterns (Observer, Factory, Singleton).

## Level 5: Templates & Meta-programming
- SFINAE and type traits.
- Variadic templates for arbitrary arguments.
- Compile-time evaluation and logic (`constexpr`, `consteval`).

## Level 6: Concurrency & Multiprocessing
- Multithreading: Mutexes, condition variables, and thread synchronization.
- Process management, `fork/exec`, and inter-process communication.

## Level 7: Networking & Messaging
- Socket programming fundamentals.
- Non-blocking sockets (`fcntl`) and I/O multiplexing (`poll`/`epoll`) on Linux.
- High-performance serialization (Protocol Buffers) and request-reply architectures (ZeroMQ).

## Level 8: GUI & Systems Integration (Hero)
- Qt framework mechanics: `QWidget`, `QProcess`, and `qobject_cast`.
- Signal and slot event loops.
- Build system automation with CMake.
